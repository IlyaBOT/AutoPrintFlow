# Раскладка стрипов и отдельные отправления

В админке откройте **«Печать и резка» → «Раскладка и отправления»**.

По умолчанию включено **«Отдельный стрип каждому аккаунту»**. Стикеры разных аккаунтов автоматически не смешиваются. У одного аккаунта может быть несколько стрипов: в каждом не более 8 стикеров. Неполный стрип не заполняется стикерами другого заказчика.

На A4 размещаются **ровно до трёх стрипов**. Четвёртый стрип начинает второй лист, седьмой — третий. Число листов считается по фактическому количеству стрипов, включая частично заполненные, а не по делению количества стикеров на 24. Например, четыре заказчика с одним стикером каждый получат четыре стрипа и два листа.

## Разделить стикеры своего аккаунта для разных получателей

1. Выберите нужные стикеры в сетке (до 8 за перенос).
2. В поле назначения оставьте **«Отдельный новый стрип»**.
3. При необходимости задайте начальный слот и метку, например «Почта — Москва».
4. Нажмите **«Перенести»**.

Аккаунт владельца не меняется: перенос задаёт только печатное расположение. Можно создать несколько отдельных отправлений для стикеров, загруженных одним аккаунтом. Ручные стрипы не получают новые стикеры автоматически. Оставшиеся стикеры сохраняют свои слоты, включая образовавшиеся промежутки.

## Перенос и обмен слотов

Слоты пронумерованы 1–8 и расположены так же, как на печатном стрипе: два столбца, четыре ряда. Выберите стикер, нужный стрип и слот, затем нажмите «Перенести». Можно также выбрать стикеры и нажать свободный слот. Групповой перенос использует свободные слоты начиная с указанного; если места недостаточно, операция отклоняется целиком.

Для обмена выберите один стикер и занятый слот другого: кнопка изменится на **«Поменять местами»**. На компьютере можно перетаскивать стикер мышью; перенос на занятый слот меняет два стикера местами. На телефоне все действия доступны через выбор и кнопки.

Стрипы, затронутые ручным переносом, сохраняют свои позиции и больше не заполняются автоматически. Непустая метка отправления также делает стрип ручным. Чтобы вернуть выбранные стикеры в общую автоматическую раскладку, нажмите **«Вернуть в авторазмещение»**.

## Переключатель разделения по аккаунтам

Если выключить разделение, автоматические стрипы пересобираются с совместным заполнением разных аккаунтов. Ручные отправления и их позиции сохраняются. Повторное включение снова разделяет только автоматически размещённые стикеры по аккаунтам. Настройка хранится в базе и сохраняется после перезапуска.

## Сохранение, экспорт и обновление

Расположение сохраняется в PostgreSQL: стабильный ID стрипа и номер слота для каждого одобренного стикера. База запрещает два стикера в одном слоте и номера слотов вне диапазона. Перенос, обмен, одобрение и отметка печати используют общую транзакционную блокировку очереди.

PNG полосы, A4, PSD и ZIP учитывают эти позиции, включая пустые слоты. `placements.json` дополнен `stripeId`, `shipmentLabel` и `customerId`. Если раскладка меняется после открытия страницы, старые экспорт и отметка печати отклоняются с ответом 409, даже когда набор стикеров остался тем же. Это защищает от работы с устаревшим макетом в другой вкладке.

Обновление выполняется прежними командами из [UPGRADE.md](UPGRADE.md). Миграция `202610161830_customer_stripe_placement` добавляется автоматически при старте приложения. Существующие одобренные стикеры при первом обращении к очереди распределяются по аккаунтам. Изображения, статусы, аккаунты и старые настройки не удаляются. Новых переменных окружения нет.
